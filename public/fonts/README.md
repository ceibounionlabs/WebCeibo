# Fuentes para el texto 3D del hero

`google-sans-500.ttf`: Google Sans Medium, subset con los caracteres del español.
Fuente: Google Fonts (https://github.com/googlefonts/googlesans). Licencia: SIL Open Font License 1.1
(https://openfontlicense.org). Se usa en TTF porque el motor de texto 3D (troika) no lee woff2.
La web en sí carga Google Sans con `next/font` (ver app/layout.tsx).
